# NotesApp user guide

NotesApp keeps your notes as plain Markdown files on your own server and shows them on every device you use: your PC, your iPhone and the desktop app. This guide shows how to do things, one task at a time. You never need to know Markdown to use it.

> [!TIP]
> In the app, open this guide with **Help**: the **?** button near the bottom of the ribbon on the left (computer), **☰ › Help** or **⋯ › Help** (phone), or type `help` in the command palette (`Ctrl+P`). The search box at the top of every Help page searches the whole guide.

Keys are written for Windows. On a Mac, press **Cmd** where the guide says **Ctrl**, and **Option** where it says **Alt**.

## Quick answers

- **How do I write code?** Type three backticks and the language, then press Enter: see [Code](writing.md#code).
- **How do I make something like a Google Sheet?** For a few numbers inside a note, use a [table with formulas](tables-and-formulas.md). For a real spreadsheet, create a [spreadsheet file](spreadsheets.md).
- **My formula shows `#NAME?`.** A function needs brackets and cells: `=SUM(B2:B4)`, not `=SUM`. See [When a formula shows an error](tables-and-formulas.md#when-a-formula-shows-an-error).
- **How do I get back yesterday's version of a note?** Open its [history](history-and-trash.md#go-back-to-an-earlier-version).
- **Something in a note looks wrong.** See [Show Markdown source](writing.md#when-something-looks-wrong).
- **Where are my bookmarks?** See [Bookmarks](search-and-bookmarks.md#bookmarks).
