# Keyboard shortcuts

Keys are written for Windows. On a Mac, press **Cmd** where it says **Ctrl**, and **Option** where it says **Alt**. The command palette (`Ctrl+P`) shows the key of every command next to its name, as set on this device, and pointing at a ribbon icon shows its key too.

## Everywhere

These work even while you are typing in a note.

| Key | Does |
|---|---|
| `Ctrl+O` | Quick switcher: open a note by name |
| `Ctrl+P` | Command palette: every action by name |
| `Ctrl+Shift+F` | Search in all notes |
| `Ctrl+Shift+Space` | Quick capture |
| `Ctrl+,` | Settings |
| `Ctrl+Alt+←`, `Ctrl+Alt+→` | Back, forward |
| `Esc` | Close the open dialog, menu or drawer |

## Notes and files

| Key | Does |
|---|---|
| `Ctrl+Alt+N` | New note |
| `F2` | Rename the open file |
| `Ctrl+S` | Save now (notes save by themselves anyway) |
| `Ctrl+;` | Add a property |
| `Ctrl+Enter` | Follow the link under the cursor |
| `Ctrl`+click | Follow a link (in a note), or open a file in a new tab (elsewhere) |

## Writing

| Key | Does |
|---|---|
| `Ctrl+B`, `Ctrl+I` | Bold, italic |
| `Ctrl+Shift+X`, `Ctrl+Shift+H` | Strikethrough, highlight |
| `Ctrl+E` | Inline code |
| `Ctrl+K` | Link (or remove a link) |
| `Ctrl+L` | Tick or untick the checkbox on this line |
| `Ctrl+Z`, `Ctrl+Shift+Z` or `Ctrl+Y` | Undo, redo |
| `Ctrl+F` | Find and replace in the note (`Ctrl+G` and `Ctrl+Shift+G` for the next and previous match) |
| `Ctrl+Shift+V` | Paste as plain text |
| `Tab`, `Shift+Tab` | Indent, outdent |
| `Alt+↑`, `Alt+↓` | Move the line up, down |
| `Shift+Alt+↓`, `Shift+Alt+↑` | Duplicate the line below, above |
| `Ctrl+Shift+[`, `Ctrl+Shift+]` | Fold, unfold the section under the cursor's heading |
| `Ctrl+Space` | Show suggestions |
| `/` | The insert menu (at the start of a line or after a space) |
| `[[`, `#` | Link to a note, add a tag |
| `Esc`, then `Tab` | Move the keyboard focus out of the note |

## Tables in notes

| Key | Does |
|---|---|
| `Tab`, `Shift+Tab` | Next, previous cell (`Tab` in the last cell adds a row) |
| `Enter`, `Shift+Enter` | Cell below, above (`Enter` in the last row adds a row) |
| `Esc` | Back to the note |
| `Shift+F10` | The cell's menu (rows, columns, alignment) |
| `Ctrl+D`, `Ctrl+R` | Fill down, fill right |

## Spreadsheets

| Key | Does |
|---|---|
| Typing, `Enter`, `F2`, double-click | Edit the cell |
| `Enter`, `Tab` | Save and move down, right (`Shift` for up, left) |
| `Esc` | Cancel the edit, or a cut |
| `Delete` | Clear the selected cells |
| `Ctrl+B` | Bold rows (or columns) |
| `Ctrl+D`, `Ctrl+R` | Fill down, fill right |
| `Ctrl+C`, `Ctrl+X`, `Ctrl+V` | Copy, cut (to move), paste |
| `Ctrl+Shift+V` | Paste values only |
| `Ctrl+Z`, `Ctrl+Shift+Z` or `Ctrl+Y` | Undo, redo |
| `Ctrl+A` | Select everything |
| `Ctrl+Space`, `Shift+Space` | Select the whole columns, the whole rows |
| `Ctrl+Arrow`, `Ctrl+Shift+Arrow` | Jump to the end of the data, select up to it |
| `Ctrl+;`, `Ctrl+Shift+;` | Today's date, the time |
| `F4` (in a formula) | Switch the cell name at the cursor between `$A$1`, `A$1`, `$A1` and `A1` |
| `Space` | Tick or untick the selected checkboxes |
| `Alt+Down` | Open a cell's drop-down list |
| `Ctrl+F`, `Ctrl+H` | Find, find and replace |

## Tabs and panes

| Key | Does |
|---|---|
| `Ctrl+Alt+T` | New tab |
| `Ctrl+Alt+W` | Close tab |
| `Ctrl+Alt+PageDown`, `Ctrl+Alt+PageUp` | Next, previous tab |
| `Ctrl+Alt+]`, `Ctrl+Alt+[` | Next, previous pane |
| `Ctrl+Shift+T` | Reopen closed tab (in the desktop app; a browser keeps this key for itself) |
| `Ctrl`+click, middle-click | Open in a new tab (in a note: `Ctrl+Shift`+click a link) |

## Lists and dialogs

| Where | Keys |
|---|---|
| Quick switcher | `↑` `↓` choose, `Enter` open, `Ctrl+Enter` open in a new tab, `Shift+Enter` create a note with that name |
| Files tab | `↑` `↓` move, `←` `→` fold and unfold folders, `Enter` open, `F2` rename, `Delete` delete, `Ctrl+Alt+N` new note in that folder |
| Task list | `Enter` or `Space` edit the task, `Alt+↑` `Alt+↓` move it, `Alt+→` make it a subtask, `Alt+←` take it out |
| Kanban board | `Alt` with the arrow keys moves the card |
| Calendar | Arrow keys by a day or a week, `Home` `End` to the week's ends, `Page Up` `Page Down` by a month (with `Shift`, a year), `Enter` opens the day's note |
| Flashcard review | `Space` or `Enter` show the answer (then answer Good), `1` to `4` answer Again to Easy, `U` undo, `E` edit, `S` skip, `Esc` end |
| PDF | `Ctrl+F` find |
| Canvas | `Delete` delete, `Enter` edit or open the selected card, `Ctrl+A` select all, `Ctrl+D` duplicate, `Ctrl+G` group, arrow keys nudge (with `Shift`, by the grid), `Ctrl+=` `Ctrl+-` zoom, `Ctrl+0` 100%, `Shift+1` zoom to fit, `Shift+2` zoom to the selection; hold `Space` and drag to move around, hold `Alt` while dragging to skip the grid |

## Change a key

Open **Settings › Hotkeys**. Find the command (type in the filter), click **Change**, and press the new key combination. **Remove** takes a key away; **Reset** brings back the default; **Reset all** resets every key. Your keys apply on this device only.

- A key needs `Ctrl`, `Alt` or a function key (`F1` to `F12`).
- If the key belongs to another command, you can take it over (**Use it here instead**); that command then has no key.
- Keys the browser keeps for itself (`Ctrl+N`, `Ctrl+T`, `Ctrl+W`, `Ctrl+Q`, `Ctrl+R`, and with `Shift`) and editing keys (`Ctrl+Z`, `Ctrl+Y`, `Ctrl+C`, `Ctrl+V`, `Ctrl+X`, `Ctrl+A`) cannot be used.

> [!NOTE]
> **Add task (quick add)** and **New tab** both have `Ctrl+Alt+T` as their default key, and New tab wins. If you add tasks often, give **Add task (quick add)** a key of its own here.

Two keys are outside NotesApp's settings: the desktop app's capture key (`Ctrl+Shift+Space`, changed from its tray icon's **Settings…**) and the browser extension's clip key (`Alt+Shift+K`).
