# Multiple vaults

A vault is a separate collection of notes, with its own folders, search, tags, history, trash, bookmarks, tasks and settings. Most people need only one. A second vault helps when two collections should never mix, for example **Personal** and **Work**.

## Make a vault

Go to **Settings › Vaults**, type a name under **New vault** and create it. It starts within a few seconds and appears in the list with an **Open** button.

(Whoever runs the server can turn off creating vaults from the app. Renaming or deleting a vault is done on the server, with the app stopped.)

## Switch vaults

Once there is more than one vault, a vault picker appears at the top of the left sidebar (phone: at the top of the drawer). Choose a vault to switch to it; **Manage vaults…** opens Settings › Vaults.

Switching loads the other vault fresh, so nothing from one vault ever shows in the other. Each vault has its own address: the first vault stays at the usual address, and another vault's pages start with `/v/<name>/`, so you can bookmark a vault or keep two vaults open in two browser tabs. An extra vault's name shows in the browser tab's title.

## What is shared and what is not

| Per vault | Shared by all vaults |
|---|---|
| Notes and files, search, tags, backlinks | The theme and other **This device** settings |
| History, trash, bookmarks | Hotkeys |
| Tasks, reminders, flashcards, habits | The devices subscribed to reminders |
| The vault's settings (Files and links, Daily notes, Templates…) | The monthly budget for Ask your vault |
| Open tabs and recent files (per device) | |

Quick capture, the web clipper, sharing from the phone and the desktop app's capture window always save into the first vault.
