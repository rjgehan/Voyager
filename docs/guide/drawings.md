# Drawings

Drawings are hand-drawn-looking diagrams and sketches, made with Excalidraw inside Voyager. Each drawing is a file in your vault, so it saves, syncs and keeps its history like a note.

## Make a drawing

- Run **Create new drawing** from the palette, or right-click a folder and choose **New drawing here**.
- Type the drawing's name and press `Enter`; the drawing opens.
- To make one while writing a note and show it right there, type `/drawing` and pick **New drawing (embedded)**.

## Draw

The tools are along the top of the drawing: select, rectangle, diamond, ellipse, arrow, line, freehand pencil, text, image and eraser. Pick a tool and drag on the page. The panel that opens beside a selected shape changes its colours, stroke and fill.

- **Phone and iPad**: draw with a finger or an Apple Pencil; pinch to zoom and drag with two fingers to move around.
- **Text**: pick the text tool (or double-click an empty spot) and type. Text in drawings is found by search.
- **Images**: paste or drop a picture onto the drawing. It is stored as a file in your vault (where attachments go), not inside the drawing, so drawings stay small.
- **Links**: text written as `[[Note]]` in a drawing, and links set on shapes, show up in that note's backlinks.

Drawings save as you draw. If you draw on two devices at once, the changes are merged.

## Show a drawing in a note

Write `![[My diagram.excalidraw]]` (or use `/embed`), and the drawing shows as a picture in the note. Add a width to size it: `![[My diagram.excalidraw|400]]`. Click the picture to open the drawing.

## Drawings from Obsidian and excalidraw.com

- Drawings made with the Obsidian Excalidraw plugin (files ending in `.excalidraw.md`) open and are edited in place, and stay readable in Obsidian.
- Files saved from excalidraw.com (`.excalidraw`) open as they are; drag them into a folder of the Files tab to add them.
- Embedded notes, embedded drawings and LaTeX formulas made with the Obsidian plugin show as pictures, but cannot be edited here.
